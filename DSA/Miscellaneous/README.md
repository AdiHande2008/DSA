# Miscellaneous

## Introduction

This folder houses problems and techniques that don't fit neatly into a single category above — including simulation problems, design questions, and hybrid-pattern problems.

## Why This Topic Is Important

Miscellaneous/design problems test the ability to combine multiple data structures and translate real-world requirements into code, a skill highly valued in interviews.

## Common Interview Questions

- LRU Cache
- Design Twitter
- Randomized Set (Insert Delete GetRandom O(1))
- Snake and Ladder simulation

## Common Patterns

- Combining multiple data structures (e.g., hash map + doubly linked list)
- Simulation-based step-by-step problems
- Object-oriented design under interview constraints
