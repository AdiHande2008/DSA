> Update the checklist as problems are added and solved. Keep the "Completed: X / Y" line in sync with the checklist below it.
>
> **How to add a new problem:**
> 1. Create the problem folder inside the relevant topic folder using the [problem template](_templates/Problem%20Name).
> 2. Add a checklist item below under the correct topic.
> 3. Update the `Completed: X / Y` count for that topic.
> 4. Update the "Overall Progress" summary table at the top.
