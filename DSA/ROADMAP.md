# 🧭 Learning Roadmap

This roadmap lists topics in a recommended learning order, grouped into four stages. Each stage builds on the previous one — resist the urge to skip ahead to Graphs/DP before fundamentals are solid.

```
   Beginner
      │
      ▼
 Intermediate
      │
      ▼
   Advanced
      │
      ▼
Interview Preparation
```

---

## Stage 1 — Beginner (Foundations)

Goal: Build comfort with basic syntax, memory model, and linear data structures.

1. [STL](STL) — containers and algorithms you'll use everywhere else
2. [Arrays](Arrays)
3. [Strings](Strings)
4. [Recursion](Recursion)
5. [Hashing](Hashing)
6. [Mathematics](Mathematics)

---

## Stage 2 — Intermediate (Core Structures & Patterns)

Goal: Learn the classic linear/non-linear structures and the algorithmic patterns built on top of arrays and strings.

7. [Two Pointers](Two%20Pointers)
8. [Sliding Window](Sliding%20Window)
9. [Prefix Sum](Prefix%20Sum)
10. [Binary Search](Binary%20Search)
11. [Bit Manipulation](Bit%20Manipulation)
12. [Linked List](Linked%20List)
13. [Stack](Stack)
14. [Queue](Queue)
15. [Deque](Deque)
16. [Backtracking](Backtracking)

---

## Stage 3 — Advanced (Trees, Graphs, DP)

Goal: Tackle hierarchical and graph-based structures, and the two biggest interview topics — DP and Greedy.

17. [Trees](Trees)
18. [Binary Search Tree](Binary%20Search%20Tree)
19. [Heap](Heap)
20. [Trie](Trie)
21. [Graph](Graph)
22. [Greedy](Greedy)
23. [Dynamic Programming](Dynamic%20Programming)

---

## Stage 4 — Interview Preparation (Specialized / Competitive Topics)

Goal: Round out knowledge with topics common in competitive programming and select advanced interviews.

24. [Number Theory](Number%20Theory)
25. [Segment Tree](Segment%20Tree)
26. [Fenwick Tree](Fenwick%20Tree)
27. [Union Find](Union%20Find)
28. [Miscellaneous](Miscellaneous) — design questions, simulations, hybrid-pattern problems

---

## Suggested Cadence

This is a starting point — adjust based on your own schedule and prior experience:

- **Weeks 1–3**: Stage 1
- **Weeks 4–8**: Stage 2
- **Weeks 9–14**: Stage 3
- **Weeks 15+**: Stage 4, then rotate back through weak topics using [PROGRESS.md](PROGRESS.md)
